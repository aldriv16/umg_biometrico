# UMG Biométrico

Sistema para control de ingreso a instalaciones mediante reconocimiento facial.

## Tecnologías
- Python 3
- CustomTkinter
- OpenCV
- face_recognition
- SQLite
- ReportLab
- QRCode

## Configuración

1. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

2. Ejecuta la aplicación:
   ```bash
   python main.py
   ```
